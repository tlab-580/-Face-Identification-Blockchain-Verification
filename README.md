# FaceChainVerify

Face Identification & Blockchain Verification Pipeline

## Overview

FaceChainVerify is an end-to-end pipeline that:

1. Accepts a face image
2. Detects and encodes the face
3. Performs genuine reverse-image/web search
4. Finds candidate social media content
5. Performs face similarity verification
6. Generates a SHA-256 fingerprint
7. Stores the fingerprint on blockchain
8. Re-verifies the discovered content
